# Handoff — {{PROJECT_NAME}}

Questa cartella coordina le consegne tra Design e Sviluppo.

## Regole

- Una slice ha un solo owner alla volta.
- La chat Design non modifica `.app-builder/state.md` né codice di produzione.
- La chat Sviluppo verifica e accetta l'handoff prima di implementare.
- Ogni handoff contiene path consentiti, acceptance criteria, verifiche e rischi aperti.
- Gli handoff chiusi restano come traccia; non vanno riscritti per sembrare più belli dopo.

Usa `HANDOFF-TEMPLATE.md` come base e assegna un ID stabile, per esempio `ONB-03-DESIGN`.
