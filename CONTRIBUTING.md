# Contribuire

Luna App Builder è in beta. Le modifiche devono mantenere il processo comprensibile anche a chi non programma.

## Regole

1. Apri una issue o descrivi chiaramente il problema risolto.
2. Lavora su una branch separata.
3. Non inserire segreti, dati personali o file appartenenti a progetti degli utenti.
4. Mantieni compatibilità tra Windows e macOS/Linux quando tocchi gli script.
5. Non aggiungere installazioni silenziose: ogni software esterno richiede consenso esplicito.
6. Aggiorna documentazione, versione e `integrity-manifest.json` quando modifichi una release.
7. Verifica JSON, YAML, sintassi shell, inizializzazione di un progetto vuoto e Doctor.

## Crediti

L'attribuzione prevista da `NOTICE`, `CREDITS.md`, `creator.json` e `LICENSE.txt` deve essere mantenuta nelle copie distribuite di App Builder.
