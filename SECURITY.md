# Security Policy

## Segnalare un problema

Non pubblicare credenziali, token, dati personali o dettagli di sfruttamento in una issue pubblica.
Per una possibile vulnerabilità, contatta privatamente il proprietario del repository tramite i canali disponibili nel profilo GitHub di `fakeOxy`.

Indica, quando possibile:

- versione o commit interessato;
- file e comportamento coinvolti;
- condizioni necessarie per riprodurre il problema;
- impatto realistico;
- una riproduzione minima che non esponga dati di terzi.

## Ambito

Sono rilevanti soprattutto problemi negli script di installazione, nei controlli Doctor, nella gestione dei percorsi, nelle istruzioni che potrebbero causare modifiche non autorizzate e nella supply chain delle dipendenze suggerite.

Luna App Builder non deve contenere segreti e non deve installare software esterno senza consenso esplicito dell'utente.
