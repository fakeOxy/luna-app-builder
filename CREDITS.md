## Integrità

La distribuzione include un manifesto SHA-256. Il controllo segnala file mancanti o modificati
rispetto alla release. Chi possiede i file può comunque alterarli e rigenerare un semplice
manifesto: la prova forte dell'origine richiede release firmate dal creatore e pubblicate da
un repository ufficiale. Il pacchetto include istruzioni per aggiungere questa firma in futuro.
